Privacy Policy - StudyTunnel2

Ultimo aggiornamento: 25 Marzo 2026

In breve: StudyTunnel2 non raccoglie, non salva e non condivide alcun dato personale o file dell'utente. La trasmissione avviene direttamente tra i tuoi dispositivi (Peer-to-Peer).

1. Raccolta dei Dati

L'estensione StudyTunnel2 e la relativa Web App non richiedono la creazione di un account né l'inserimento di dati personali (nome, email, ecc.). Tutti i file e i testi inviati tramite l'applicazione rimangono privati.

2. Trasmissione dei Dati (P2P)

I dati vengono inviati utilizzando la tecnologia WebRTC (Peer-to-Peer) tramite la libreria PeerJS. Questo significa che il file passa direttamente dal tuo telefono al tuo computer (o viceversa) senza mai fermarsi su un server centrale.

I server di PeerJS vengono utilizzati esclusivamente per mettere in contatto i due dispositivi (fase di "handshake") tramite un ID univoco temporaneo, ma non hanno accesso al contenuto dei dati trasmessi.

3. Sicurezza

La connessione P2P è crittografata end-to-end per impostazione predefinita dal protocollo WebRTC. Inoltre, abbiamo implementato un sistema di Token Segreto: solo il dispositivo che scansiona il tuo QR Code unico può comunicare con la tua estensione.

4. Permessi dell'Estensione

  • clipboardWrite: Utilizzato solo per permetterti di copiare velocemente il testo o l'immagine ricevuta negli appunti.
  • storage: Utilizzato per salvare localmente la cronologia degli ultimi 10 elementi ricevuti sul tuo computer. Questi dati non lasciano mai il tuo dispositivo.

5. Contatti

Per qualsiasi domanda, puoi contattare lo sviluppatore tramite il repository GitHub del progetto.
